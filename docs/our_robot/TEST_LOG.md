# 주차로봇 벤치 시험 기록

최종 정리: 2026-08-19

이 문서는 날짜별 실측값과 문제 해결 과정을 보관하는 참고 기록이다. 최종 핀·전압·안전 한계는 `ELECTRICAL_WIRING.md`, 시스템 설계는 `SYSTEM_HANDOFF.md`를 우선한다.

## 2026-07-29

- XL4015 #1을 5.1V로 설정해 Raspberry Pi 4를 구동하면서 STM32 USB 통신과 통합 제어가 동작함을 확인했다.
- HC-SR04 #1·#2가 타임아웃 없이 각각 57mm, 79mm를 반환했다. 기준 물체까지의 실제 거리를 함께 측정하지 않았으므로 정확도 보정값으로 사용하지 않는다.

## 2026-08-03

- MDD10A #1의 M1/M2 모터 출력 묶음이 교차되면 제어 채널과 엔코더 피드백이 바뀌어 PID가 포화되는 현상을 확인했다.
- 최종 대응은 MDD10A #1 M1=FL, M2=FR로 정리했다.
- 한 채널이 DIR 한쪽에서 정지하고 반대쪽에서 과속할 때 PWM/DIR 입력선 교차를 먼저 확인해야 한다.

## 모터·엔코더 벤치 시험

- 엔코더 A/B는 풀업 없이 0V에 머물렀고 STM32 입력에 `GPIO_PULLUP`을 적용한 뒤 정상 카운트됐다.
- 기준 모터 출력축을 5회전시켜 총 25,908카운트, 1회전당 약 5,182카운트를 확인했다. STM32 4체배 값이며 모터축 PPR은 아니다.
- 같은 PWM·1.5초 조건의 양방향 카운트는 약 1,469~1,515였고 방향에 따라 부호가 반대였다.
- 4륜 PI 제어의 무부하 목표는 약 12RPM이었다. 정상상태에서 주로 11.1~12.0RPM, 보정 PWM 약 186~216을 확인했다.
- 목표 속도는 50ms마다 1RPM씩 변경해 0→12RPM에 약 0.6초가 걸렸다. 정지 명령과 250ms 통신 단절은 가속·감속 램프 없이 즉시 PWM 0을 적용했다.
- 위 값은 벤치 조건 기록이며 최종 바퀴·하중 상태의 모터별 튜닝값으로 확정하지 않는다.

## 로봇별 서보 시험

- `robot-1` 무마커 프로파일은 시작 400/2600µs, 닫힘 한계 1600/1400µs에서 추가 닫힘 명령에도 멈췄고 다시 400/2600µs로 복귀했다.
- 초기 단계 시험에서 `robot-1`에 닫기 명령 1회를 주면 450/2550µs, 열기 명령 1회를 주면 400/2600µs로 복귀했다.
- `robot-2` ArUco 프로파일은 시작 2600/400µs, 닫힘 한계 1550/1450µs에서 추가 닫힘 명령에도 멈췄고 1500µs에 도달하거나 서로 교차하지 않았다.
- 두 프로파일 모두 최종 차량 하중과 동시 서보 동작에서 6.0V 전압강하·발열을 다시 확인해야 한다.
