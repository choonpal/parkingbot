# 주차로봇 전장·배선 제작서

최종 갱신: 2026-09-04 (카메라 구성 정정; 전원·핀맵 유지)
대상: 기본 배선은 로봇 2대에 동일 적용, 서보 제어 프로파일은 장착 방향별로 구분
전원: 12V 납축전지 2개 직렬, 24V
제어: Raspberry Pi 4 + STM32 Nucleo F401RE

## 1. 확정 구성

- 주행 모터: RB-35GM+Encoder DC24V, 1/100 ×4/로봇
- 모터드라이버: Cytron MDD10A ×2/로봇
- 인양 서보: MG996R ×2/로봇, 6.0V부터 설정
- 초음파: HC-SR04 ×2/로봇
- 로봇 카메라: OV2710 USB ×1/로봇 (Rear ID0 상대측위, Front 보조 영상/확장용)
- 천장 카메라: Logitech C920 ×1 + C922 ×1, Jetson USB 연결
- 전원 분배: TB-2506 ×1/로봇
- 메인 스위치: 1NC 비상정지 스위치가 평상시 ON/OFF와 비상 차단을 겸함
- 메카넘 역기구학·휠 PID: STM32 담당

부품 수량과 구매 상태는 [`BOM.md`](BOM.md)를 우선한다.

## 2. 전체 전원 구조

```text
[Battery A 12V]                [Battery B 12V]
 A(-) = PACK -                   B(+) = PACK +
 A(+) ───── 14AWG 직렬 점퍼 ───── B(-)

PACK +
  → ATO 20A 퓨즈
  → 배터리 측 XT60 암(+)
  ⇄ 로봇 측 XT60 수(+)
  → 비상정지 COM → NC
  → TB-2506 +24V BUS(1~3극)

PACK -
  → 배터리 측 XT60 암(-)
  ⇄ 로봇 측 XT60 수(-)
  → TB-2506 GND BUS(4~6극)
```

퓨즈는 Battery B(+) 바로 뒤에 최대한 가깝게 설치한다. 비상정지 스위치는 정상 상태에서 COM-NC가 도통되고 버튼을 누르면 열려야 한다. 평상시 전원 스위치로도 사용하되 모터와 서보가 정지한 상태에서 조작한다.

### 2.1 단일 메인 전원 제약

현재 조립 상태는 메인 스위치/비상정지 뒤의 전원을 한 번에 인가하며, RPi와
카메라만 켜고 모터 계통만 별도로 OFF하는 운용 스위치가 없다. 따라서 문서에서
말하는 `motor OFF + camera/UART ON` 상태를 스위치 조작만으로 만들 수 없다.

카메라·ArUco·UART 같은 정적 점검도 공통 전원을 켜기 전에 로봇을 견고한 받침대에
올려 **모든 바퀴를 바닥에서 띄운다**. 점검용 ROS domain을 운용 domain과 분리하고,
STM32 bridge·상태기계·motion controller를 실행하지 않으며 `cmd_vel` publisher가
0개인지 확인한다. 물리 비상정지는 작업자가 즉시 누를 수 있어야 하고 사람과
케이블을 바퀴·서보의 작동 범위에서 치운다. 이 절차는 독립 motor-power 차단과
동등한 하드웨어 안전 기능이 아니며, 바닥에 로봇을 둔 채 정적 점검하는 근거로
사용하지 않는다.

## 4. TB-2506 한 개로 +24V/GND 분배

TB-2506은 6극이며 각 극의 마주 보는 두 나사칸이 내부에서 연결되어 총 12개 체결점을 제공한다. 각 극의 두 나사칸을 A/B로 표기한다.

- 1~3극: +24V BUS
- 4~6극: GND BUS
- VLT-SB017 6P 쇼트바는 3P 두 구간으로 완전히 분리
- 쇼트바 1~3 연결부와 4~6 연결부 사이에 전기적 접촉이 없어야 함

| 극/칸 | 연결 대상 | 전선 |
|---|---|---|
| 1A | 메인 +24V 입력(비상정지 NC 이후) | 14AWG 빨강 |
| 1B | MDD10A #1 VB+ | 14AWG 빨강 |
| 2A | MDD10A #2 VB+ | 14AWG 빨강 |
| 2B | XL4015 #1 IN+ | 16AWG 빨강 |
| 3A | XL4015 #2 IN+ | 16AWG 빨강 |
| 3B | SZH-BCV002 빨강 | 16AWG 빨강 |
| 4A | 메인 GND 입력(XT60 수 -) | 14AWG 검정 |
| 4B | MDD10A #1 VB- | 14AWG 검정 |
| 5A | MDD10A #2 VB- | 14AWG 검정 |
| 5B | XL4015 #1 IN- | 16AWG 검정 |
| 6A | XL4015 #2 IN- | 16AWG 검정 |
| 6B | SZH-BCV002 검정 | 16AWG 검정 |

TB-2506에는 M4 링 단자를 사용한다. 쇼트바와 링 단자를 같은 나사에 체결할 때는 서로 평평하게 밀착되고 나사가 충분히 물리는지 확인한다. 통전 전 멀티미터로 1~3극 상호 도통, 4~6극 상호 도통, 3극↔4극 절연을 확인한다.

## 5. 전압·온도 표시기

| 표시계 선 | 연결 위치 |
|---|---|
| 빨강 | TB-2506 3B(+24V) |
| 검정 | TB-2506 6B(GND) |
| 온도 센서선 | 배터리 케이스 옆면 중앙 |

표시계는 비상정지 뒤쪽 BUS에 병렬 연결하므로 전원이 켜졌을 때만 표시된다. 잔량 퍼센트는 전압 기반 참고값으로만 사용한다.

## 6. 충전 어댑터

PB-2402CR의 출력은 XT60 수 커넥터로 제작한다.

| 충전기 출력선 | XT60 수 |
|---|---|
| 빨강 | + |
| 검정 | - |

충전 순서:

1. Raspberry Pi 4를 정상 종료한다.
2. 충전기 AC 플러그가 분리됐는지 확인한다.
3. 배터리 측 XT60 암과 로봇 측 XT60 수를 분리한다.
4. 배터리 측 XT60 암에 충전 어댑터 XT60 수를 연결한다.
5. 충전기 AC 플러그를 연결한다.
6. 완료 후 AC 플러그를 먼저 분리한다.
7. 충전 어댑터를 제거하고 로봇을 다시 연결한다.

충전 중에는 로봇을 구동하지 않는다. 직렬로 묶는 두 배터리는 모델·용량·상태가 비슷한 조합으로 고정한다.

## 7. Raspberry Pi 4·STM32·카메라

### 7.1 Raspberry Pi 4 전원

```text
TB-2506 2B/5B → XL4015 #1 IN+/IN-
XL4015 #1 OUT+/OUT- → 5.1V 조정
→ USB-C 전원 보드 VBUS/GND
→ Raspberry Pi 4 USB-C
```

RPi4 연결 전 무부하 5.1V로 맞추고, 부팅·USB 부하 상태에서도 저전압 경고가 없는지 확인한다. 과거 동작 수치는 `TEST_LOG.md`에 기록한다.

### 7.2 STM32 통신

```text
RPi4 USB-A → USB-A to Mini-B → Nucleo F401RE ST-LINK USB
```

이 연결로 Nucleo 급전과 ST-LINK Virtual COM Port 통신을 함께 수행한다. Linux 장치명은 일반적으로 `/dev/ttyACM0`이다.

### 7.3 전면 카메라

```text
RPi4 USB-A → OV2710 USB 카메라
```

Rear 카메라는 Front 후면 ID0를 관측한다. Front 카메라는 보조 영상/확장용으로,
현재 production Front launch의 필수 인식경로에는 포함되지 않는다.
보정 자산은 [카메라·실측 기준](CAMERA_CALIBRATION_BASELINE.md)을 따른다.

## 8. STM32–MDD10A–모터

### 8.1 Nucleo F401RE 물리 헤더 빠른 배선표

보드의 ST-LINK Mini-B USB가 위쪽을 향하도록 놓는다. CN7은 왼쪽, CN10은 오른쪽의 2×19핀 수 헤더다. 각 헤더의 USB 쪽 첫 줄이 1·2번이며, 기판의 `1` 표시가 있는 열을 따라 1·3·5…·37번, 반대 열을 따라 2·4·6…·38번이 내려간다. CN7/CN10에는 암 점퍼 단자를 사용하고, CN5/CN6/CN8/CN9의 Arduino 암 소켓에는 수 점퍼 단자를 사용한다.

아래 표의 **주 연결 위치**를 우선 사용한다. 괄호 안 `D/A` 위치는 동일한 MCU 신호가 노출된 대체 구멍이므로 둘 중 하나만 연결한다.

| 분류 | 대상 | 신호 | MCU 핀 | 주 연결 위치 | 같은 신호의 대체 위치 |
|---|---|---|---|---|---|
| 모터 | FL | PWM | PA8 | CN10-23 | D7, CN9-8 |
| 모터 | FL | DIR | PC0 | CN7-38 | A5, CN8-6 |
| 모터 | FR | PWM | PA9 | CN10-21 | D8, CN5-1 |
| 모터 | FR | DIR | PC1 | CN7-36 | A4, CN8-5 |
| 모터 | RR | PWM | PA10 | CN10-33 | D2, CN9-3 |
| 모터 | RR | DIR | PC2 | CN7-35 | - |
| 모터 | RL | PWM | PA11 | CN10-14 | - |
| 모터 | RL | DIR | PC3 | CN7-37 | - |
| 엔코더 | FL | A(보라) | PA0 | CN7-28 | A0, CN8-1 |
| 엔코더 | FL | B(파랑) | PA1 | CN7-30 | A1, CN8-2 |
| 엔코더 | FR | A(보라) | PA15 | CN7-17 | - |
| 엔코더 | FR | B(파랑) | PB3 | CN10-31 | D3, CN9-4 |
| 엔코더 | RL | A(보라) | PB4 | CN10-27 | D5, CN9-6 |
| 엔코더 | RL | B(파랑) | PB5 | CN10-29 | D4, CN9-5 |
| 엔코더 | RR | A(보라) | PB6 | CN10-17 | D10, CN5-3 |
| 엔코더 | RR | B(파랑) | PB7 | CN7-21 | - |
| 서보 | #1 | 신호 | PB8 | CN10-3 | D15, CN5-10 |
| 서보 | #2 | 신호 | PB9 | CN10-5 | D14, CN5-9 |
| 초음파 | #1 | TRIG | PC8 | CN10-2 | - |
| 초음파 | #1 | ECHO | PC6 | CN10-4 | - |
| 초음파 | #2 | TRIG | PC5 | CN10-6 | - |
| 초음파 | #2 | ECHO | PC7 | CN10-19 | D9, CN5-2 |
| 공통 | 센서 5V 레일 | +5V | - | CN7-18 | CN6-5 |
| 공통 | GND 레일 | GND | - | CN7-20 | CN6-6 또는 CN6-7 |

엔코더의 갈색은 VCC 5V, 초록은 GND, 보라는 A, 파랑은 B다. 빨강과 검정은 모터 전원선이며 STM32에 연결하지 않고 해당 MDD10A 출력으로 보낸다. 서보는 외부 XL4015 6.0V에서 급전하고 STM32에는 신호와 공통 GND만 연결한다. Nucleo 5V 레일에서 서보를 급전하지 않는다.

| 드라이버 | 담당 모터 |
|---|---|
| MDD10A #1 | FL, FR |
| MDD10A #2 | RR, RL |

| STM32 핀 | 연결 대상 | 역할 |
|---|---|---|
| PA8 | MDD10A #1 PWM1 | FL PWM |
| PC0 | MDD10A #1 DIR1 | FL 방향 |
| PA9 | MDD10A #1 PWM2 | FR PWM |
| PC1 | MDD10A #1 DIR2 | FR 방향 |
| PA10 | MDD10A #2 PWM1 | RR PWM |
| PC2 | MDD10A #2 DIR1 | RR 방향 |
| PA11 | MDD10A #2 PWM2 | RL PWM |
| PC3 | MDD10A #2 DIR2 | RL 방향 |
| GND | 두 MDD10A Logic GND | 신호 기준 |

| MDD10A 출력 | 모터 |
|---|---|
| #1 M1A/M1B | FL |
| #1 M2A/M2B | FR |
| #2 M1A/M1B | RR |
| #2 M2A/M2B | RL |

모터 출력 두 가닥 묶음은 위 채널 대응대로 연결한다. 채널과 엔코더 피드백이 서로 바뀌면 PID가 포화될 수 있다. 한 채널이 DIR 한쪽에서 정지하고 반대쪽에서 과속하면 PID보다 PWM/DIR 입력선 교차 여부를 먼저 확인한다.

MDD10A의 Vmotor 극성을 통전 전에 재확인한다. 모터 전원선은 16AWG를 사용하고 모터 탭은 각각 납땜 후 따로 열수축한다.

## 9. 엔코더

| 엔코더 | VCC | GND | A | B | STM32 타이머 |
|---|---|---|---|---|---|
| FL | 5V | GND | PA0 (CN7-28) | PA1 (CN7-30) | TIM5 |
| FR | 5V | GND | PA15 (CN7-17) | PB3 (CN10-31/D3) | TIM2 |
| RL | 5V | GND | PB4 (CN10-27/D5) | PB5 (CN10-29/D4) | TIM3 |
| RR | 5V | GND | PB6 (CN10-17/D10) | PB7 (CN7-21) | TIM4 |

엔코더 A/B에는 STM32 내부 풀업(`GPIO_PULLUP`)이 필요하다. 네 타이머는 Encoder Mode TI1/TI2, Input Filter 4를 사용한다. 초기 환산값은 STM32 4체배 기준 출력축 1회전당 약 5,182카운트이며 모터축 PPR이 아니다. 나머지 모터와 최종 바퀴·하중 상태에서 각각 재검증한다. 엔코더선은 모터 전원선과 떨어뜨려 배선한다. 상세 실측 과정은 `TEST_LOG.md`에 기록한다.

## 10. MG996R 서보

### 10.1 전원

```text
TB-2506 3A/6A → XL4015 #2 IN+/IN-
XL4015 #2 OUT+ → MG996R #1·#2 빨강
XL4015 #2 OUT- → MG996R #1·#2 갈색/검정
```

XL4015 #2는 6.0V부터 설정한다. 서보 두 개는 Nucleo 5V 핀에서 급전하지 않는다. 두 서보 동시 기동 시 전압강하와 발열을 확인하고 펌웨어 soft-start를 적용한다.

### 10.2 신호

| STM32 핀 | 연결 |
|---|---|
| PB8 | MG996R #1(오른쪽, `U/J`) 신호 |
| PB9 | MG996R #2(왼쪽, `I/K`) 신호 |
| GND | 서보 전원 GND와 공통 |

PWM은 50Hz이며 부팅 시 서보 PWM은 비활성 상태다. 조작 명령이 처음 들어올 때 현재 프로파일의 벌림 위치부터 시작해 20ms마다 30µs씩 목표 펄스로 이동한다. `X`를 받으면 현재 위치를 유지하며, Raspberry Pi 수동 제어기는 마지막 서보 키 입력 후 0.30초에 `X`를 전송한다. `T`는 양쪽 동시 닫기, `G`는 양쪽 동시 벌리기, `O`는 두 서보 PWM 해제다. 서보 명령 중에는 주행 모터를 정지한다.

| 로봇 프로파일 | 서보 #1 오른쪽 벌림·허용 범위 | 서보 #2 왼쪽 벌림·허용 범위 | 닫힘 안전 한계 | 확인 결과 |
|---|---|---|---|---|
| ArUco 장착 (`robot-2`) | 시작 2600µs, 1550~2600µs | 시작 400µs, 400~1450µs | 1550 / 1450µs | 1500µs를 지나 서로 교차하지 않음. 추가 `T` 명령에도 한계 유지 확인. |
| 무마커 (`robot-1`) | 시작 400µs, 400~1600µs | 시작 2600µs, 1400~2600µs | 1600 / 1400µs | 바퀴를 들 수 있는 위치이며, 추가 `T` 명령에도 한계 유지 확인. |

두 프로파일의 시작값·허용 범위는 STM32 펌웨어에서 강제하므로, Raspberry Pi 또는 다른 UART 송신기가 잘못된 닫힘 명령을 보내도 안전 한계를 넘지 않는다. 최종 차량 하중 시험에서 인양 한계를 재확인한다.

## 11. HC-SR04 ×2/로봇

| 센서 | VCC | GND | TRIG | ECHO |
|---|---|---|---|---|
| HC-SR04 #1 | 5V | GND | PC8 (CN10-2) | PC6 (CN10-4) |
| HC-SR04 #2 | 5V | GND | PC5 (CN10-6) | PC7 (CN10-19, Arduino D9) |

STM32F401RE 데이터시트의 핀 정의에서 PC6과 PC7은 `FT`(5V 허용 디지털 I/O)로 확인되므로, GPIO 디지털 입력 모드에서는 HC-SR04 Echo를 직접 연결할 수 있다. MCU가 꺼진 상태에서 센서 Echo만 인가하지 않으며, 다른 MCU 핀으로 변경할 때는 해당 핀의 5V 허용 여부를 다시 확인한다. 센서는 타이어 높이 부근에 설치하고 모터선과 떨어뜨린다.

개발용 키보드 명령 `1`과 `2`로 센서를 한 개씩 발사한다. 상호 간섭을 줄이기 위해 측정 사이에 최소 60ms 간격을 둔다. 응답 확인용 과거 거리값은 보정값으로 사용하지 않으며 `TEST_LOG.md`에만 보관한다.

## 13. 공통 GND

다음 GND는 전기적으로 공통이어야 한다.

```text
Battery A(-)
TB-2506 GND BUS(4~6극)
MDD10A #1·#2 VB-
XL4015 #1·#2 IN-/OUT-
Raspberry Pi 4 GND
STM32 GND
엔코더 GND
서보 GND
HC-SR04 GND
```

## 14. 배선 작업 규칙

- +24V·양전원은 빨강, GND는 검정으로 통일한다.
- TB-2506은 M4 링 단자, MDD10A·XL4015 삽입형 단자는 페룰을 사용한다.
- 배터리 탭은 6.35mm 절연 암 스페이드, XT60은 납땜+열수축으로 마감한다.
- 압착 후 당김 시험을 하고, 실패한 단자는 재사용하지 않는다.
- 모든 모터·엔코더·서보·센서 선 양 끝에 동일 라벨을 붙인다.
- 납땜 전에 열수축 튜브를 먼저 끼운다.
- 배터리 위에 금속 공구를 두지 않고 반지·시계 등을 제거한다.

## 15. 통전 전 체크리스트

- [ ] Battery A(+)와 Battery B(-)가 직렬 연결됨
- [ ] Battery B(+) 직후에 ATO 20A 퓨즈홀더가 위치함
- [ ] XT60 암/수의 +·- 극성이 일치함
- [ ] 비상정지 COM-NC가 정상 도통되고 누르면 열림
- [ ] TB-2506 1~3극만 상호 도통됨
- [ ] TB-2506 4~6극만 상호 도통됨
- [ ] TB-2506 3극과 4극 사이가 절연됨
- [ ] 쇼트바 절단부와 금속 노출부가 절연됨
- [ ] XL4015 #1 출력이 5.1V임
- [ ] XL4015 #2 출력이 6.0V임
- [ ] 공통 GND 연속성을 확인함
- [ ] 모든 압착부가 당김 시험을 통과함
- [ ] 모든 납땜부가 열수축 마감됨
- [ ] 퓨즈는 모든 검사 후 마지막에 삽입함

## 16. 첫 통전 순서

1. 로봇을 견고한 받침대에 올려 모든 바퀴를 띄우고 BUS 전압과 벅 출력 확인
2. Raspberry Pi 4 부팅과 저전압 경고 확인
3. STM32 USB/VCP 인식 확인
4. 전압·온도 표시계 확인
5. 서보를 기구 부하 없이 하나씩 시험
6. 바퀴를 공중에 띄우고 모터를 하나씩 시험
7. 엔코더 값·방향·실측 카운트 확인
8. HC-SR04 두 개 거리값 확인
9. OV2710 영상 확인
10. ROS2↔STM32 통신과 Heartbeat 정지 동작 확인

이상 발열, 냄새, 연기, 비정상 소음이 발생하면 즉시 비상정지를 누르고 XT60을 분리한다.
